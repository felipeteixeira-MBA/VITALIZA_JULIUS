# Experimentos preservados, não pipeline canônico

Estes scripts foram produzidos nas etapas anteriores. São referências para aprendizagem e migração, não comandos ativos de produção. Seus caminhos relativos pressupõem o ambiente original da conversa, e alguns dependem de derivados já construídos.

**Os cálculos antigos de pagamentos podem conter duplicidades funcionais.** Não use esses totais como faturamento corrigido. O código canônico é o módulo em `src/vitaliza_case`.

Alguns scripts imprimem amostras de cadastro ou logs. Não publique suas saídas sem revisão. Dados brutos e modelos não acompanham esses scripts. A inclusão neste histórico não afirma que todos foram reexecutados e validados nesta preparação.
